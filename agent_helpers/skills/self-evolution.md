# 🧬 Self-Evolution Skill (Meta-Cognitive Optimization)

**Trigger:** Explicit Super Command, periodic system maintenance, or post-failure backpropagation.

---

## 🎯 Purpose
To provide Axon with a deterministic, self-directed methodology for inspecting its own prompt performance, state transition latencies, memory palace integrity, persona alignment, and code verification routines, and systematically upgrading itself without human intervention.

---

## 🔄 The 4-Step Self-Evolution Loop

```
┌─────────────────────────┐     ┌─────────────────────────┐
│ 1. Meta-Reflection     │ ──> │ 2. Integrity Audit      │
└─────────────────────────┘     └─────────────────────────┘
             ▲                               │
             │                               ▼
┌─────────────────────────┐     ┌─────────────────────────┐
│ 4. Memory Consolidation │ <── │ 3. Self-Modification    │
└─────────────────────────┘     └─────────────────────────┘
```

### Step 1: Meta-Reflection
- Inspect current session state and recent errors.
- Evaluate if prompt instructions or persona definitions produced ambiguity.
- Identify missing atomic neurons or dead links in `neocortex/INDEX.md`.

### Step 2: Integrity Audit
- Run automated codebase health check scripts (e.g., `pytest`, `marimo check`, or `self_reflection_audit.py`).
- Inspect frontmatter of all Neocortex neurons for missing `neuron_id`, `synaptic_weight`, `corpus_callosum`, or invalid file links.

### Step 3: Self-Modification
- Update or refactor skills, templates, personas, or neocortex neurons.
- Enhance script resilience, error handling, or performance telemetry.
- Re-run verification commands to confirm 0 regressions.

### Step 4: Memory Consolidation
- Record the self-evolution cycle in `memory/episodic_log.md`.
- Update `memory/session_state.md` with the new capability or structural optimization.
- Return to `[STATE 1: SENSORY_INGESTION]`.

---

## 🔒 Safety Constraints
1. **Zero Degradation**: Pass rate of existing tests must remain 100%.
2. **Immutable Laws**: The 19 Laws in `CONSCIENCE.md` are inviolable.
3. **Traceability**: All self-modifications must be explicitly logged with UTC timestamps.
