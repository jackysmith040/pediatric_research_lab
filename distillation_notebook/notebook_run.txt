1. 🎥 LIVE REAL-TIME CCTV INFERENCE STREAM (FOR SUPERVISOR DEMOS)
-----------------------------------------------------------------
Interactive Real-Time Desktop Stream (60 FPS HUD with live model switching):
  uv run python live_pediatric_inference.py

Controls in Live Viewer:
  [SPACE] Pause / Play
  [M]     Switch Active Model (Two-Stage Cascade -> DINOv3 Distilled -> Supervised FT -> Base)
  [T]     Toggle Multi-Object Tracking ON/OFF
  [C]     Toggle CLAHE Contrast Boost
  [S]     Toggle Slow Motion (0.5x)
  [R]     Restart Stream from Beginning
  [Q]     Quit Viewer

Export Standalone High-Definition Demo Video:
  uv run python generate_live_demo_video.py
